## 📋 Management Rules (운영 원칙)

공개된 저장소로서 문서의 신뢰성과 일관성을 유지하기 위해 다음 규칙을 준수합니다.

1.  **Data-Driven**: 모든 성과는 수치(Metrics)와 증빙(Screen-shots)을 바탕으로 기록합니다.
2.  **Trade-off Analysis**: 특정 기술을 선택한 이유와 포기한 대안에 대한 근거를 명시합니다.
3.  **Privacy First**: 프로젝트의 비즈니스 로직과 민감한 내부 정보는 비식별화 처리하여 보안을 준수합니다.
4.  **Continuous Update**: 지식의 휘발을 막기 위해 이슈 해결 직후 '작성일' 기준으로 아카이빙합니다.
