# 이재필

## 백엔드 개발자

Java/Spring 기반의 백엔드 개발 경험을 보유하고 있으며, API·데이터 처리 및 기존 시스템 개선 업무를 수행했습니다.

기존 시스템의 동작과 병목 구간을 분석하고, 알고리즘 및 데이터 처리 방식을 개선하여 성능을 향상시킨 경험이 있습니다.

실무 경험을 기반으로 백엔드 개발 역량을 확장하고 있으며, 서비스 및 AI 백엔드 영역으로의 확장을 목표로 하고 있습니다.

## 핵심 역량

### 백엔드 개발

* Java/Spring 기반 백엔드 개발
* Spring Boot 기반 애플리케이션 개발
* REST API 및 시스템 연계
* 기존 업무 시스템 분석 및 기능 개선
* 요구사항 분석 및 기존 코드 구조 파악

### 데이터베이스 및 데이터 처리

* Oracle, PostgreSQL, SQL
* 데이터 조회 및 가공
* 객체 간 매핑 구조 분석 및 개선
* 대용량 데이터 처리 및 SQL 개선

### 문제 분석 및 개선

* 실행 성능 분석
* 알고리즘 복잡도 개선
* 시스템 간 데이터 흐름 및 인터페이스 분석
* 기존 시스템 구조 분석
* 반복 코드 제거 및 공통화

## 주요 개발 경험

### 신한라이프 영업지원시스템

**2025.11 – 2026.01**

**성능 개선**

* 기존 시스템의 처리 성능 및 병목 구간 분석
* 반복적인 데이터 탐색 로직의 실행 구조 분석
* 데이터 처리 과정에서 발생하는 알고리즘 복잡도 문제 확인
* **O(n²) → O(n)** 방식으로 데이터 탐색 로직 개선
* 데이터 처리 및 브라우저 화면 출력 방식 개선
* 변경 전후 처리시간을 측정하여 개선 효과 검증
* **처리시간 약 20.6초 → 6.2초로 단축**
